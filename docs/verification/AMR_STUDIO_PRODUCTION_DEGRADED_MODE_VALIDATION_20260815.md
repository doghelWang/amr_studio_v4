## 1. 本轮修复

针对生产共享域名的 `/api/*` 仍被其他 Worker 路由截获的问题，增加前端可解释降级：

- 后端状态请求失败时保持离线状态，不再重复输出误导性的 error 日志。
- 已保存项目 API 失败时读取仓库已有 `worker-data/user-saves-index.json`，显示为“只读验证快照”。
- 点击快照项目时读取对应的 `worker-data/user-saves/{name}.json`。
- 保存、编译和其他需要真实后端的操作仍走 API，失败时不伪装成功。

## 3. 仍需外部配置解决的问题

生产域名的 `/api/v1/system/version`、`/api/v1/projects/saved-list` 和 `/api/v1/schemas` 仍未进入 `amr-studio-v4` Worker；当前降级模式只解决只读验证体验。需要域名所有者确认并调整共享路由后，才能恢复实时 API、KV 保存和在线模块注册表。

## 4. 数据真实性边界

本轮使用的项目列表和项目配置来自仓库已存在的生成快照，仅用于只读验证。页面已明确标注来源；没有把快照当作远程 KV 数据，也没有为保存、编译接口构造成功结果。
