## 9. Step 4 可视化器视觉优化总结

### 9.1 LiDAR 传感器视觉表现

**优化前:**
- 简单的锥形FOV + 箭头线指示方向
- 单一填充色块

**优化后:**
```
LiDAR 样式特征:
┌────────────────────────────────────────┐
│  ◐ 同心圆范围环 (25%, 50%, 75%)       │
│     - 虚线/实线交替                    │
│     - 透明度递减                       │
│  ◑ 半透明锥形覆盖区域                  │
│     - 深色主题: opacity 0.06           │
│     - 浅色主题: opacity 0.04           │
│  ◒ 中心方向指示线                      │
│     - 粗线 (strokeWidth: 2.5)          │
│     - 长度 60px (非150px箭头)          │
│  ◓ 中心点标记                          │
│     - 半径 3px                         │
└────────────────────────────────────────┘
```

**代码实现要点:**
- 36段高分辨率弧线 (vs 原来24段)
- 三层同心扫描弧线 + 一层虚线
- 移除箭头，改用直线标记方向
- FOV扇形更透明，避免遮挡底盘

**俯视图 (Top):**

```
轮组俯视图:

│    ╱   ◯   ╲   ← 轮胎 (椭圆)        │
```

### 9.3 相机视觉表现

**优化后:**
```
相机样式 (俯视):
┌────────────────┐
│   ┌────────┐   │
│   │  ◯    │   │  ← 镜头 (双圆环)

└────────────────┘

相机样式 (轴侧):
┌────────────────────┐
│     ┌────┐         │
```

**特征:**

- 轴侧图: 矩形机身 + 突出的镜头矩形
- 激活时镜头变蓝色

### 9.4 FOV 渲染优化

**渲染参数调整:**
```typescript
const FOV_CONFIG = {
  // 分段数 - 提高平滑度
  segments: 36, // was 24
  
  // 同心扫描弧线 (LiDAR特有)
  scanArcs: [0.25, 0.5, 0.75], // 25%, 50%, 75%范围
  
  // 透明度配置
  fillOpacity: {
    dark: 0.06,  // was 0.15
    light: 0.04, // was 0.1
  },
  
  // 线条样式
  lineOpacity: [0.35, 0.25, 0.15], // 三层递减
  strokeDashArray: ['none', '3 2', 'none'], // 中间层虚线
  
  // 方向指示器 (替代箭头)
  directionLine: {
    length: 60,   // was 150
    width: 2.5,   // was 2
    hasArrowHead: false, // 移除箭头
  },
};
```

### 9.5 视觉层次规范

**组件绘制优先级 (从底到顶):**
```
1. 网格背景 (grid)
2. 底盘轮廓 (chassis)
3. FOV 覆盖层 (半透明)
4. 组件主体
5. 选中高亮效果 (glow filter)
6. 标签文字
```

**透明度设计原则:**
- FOV 填充: 极低 (0.04-0.06)，避免遮挡
- 扫描线: 中等 (0.15-0.35)，提供参考
- 轮廓线: 较高 (0.3-0.5)，清晰可见
- 激活组件: 高亮发光效果

### 9.7 界面设计规范补充

**FOV 显示约束:**
```
□ LiDAR: 270度广角覆盖
  - 显示同心扫描环
  - 中心方向指示线
  - 无箭头标记

□ Camera: 90度视场角
  - 简化锥形
  - 无同心环

□ 其他传感器: 不显示FOV

□ 所有视图均支持点击选中
```

**轮组显示约束:**
```
□ 轴侧图: 显示轮胎纹理细节
□ 俯视图: 椭圆形态 + 方向线
□ 箭头禁用，用直线表示方向
□ 激活态有发光效果
```
