

## 10. 可视化器重设计 - 问题分析与解决方案

### 10.1 问题根因分析

**用户反馈的问题:**
1. 侧视图中车体是3D效果，但轮组、激光像"杆子"竖着
2. 角度与车体模型不一致
3. 俯视图看不懂，不如最初版本

### 10.2 统一渲染架构设计

**核心原则: 底盘和组件使用相同的投影函数**

```typescript
// 统一的投影函数 - 所有元素共用
const projectPoint = (
  x: number, y: number, z: number,
  type: 'iso' | 'top',
  centerX: number, centerY: number,
  scale: number
) => {
  if (type === 'iso') {
    // 等轴测投影
    const angle = Math.PI / 6; // 30度
    const isoX = (x - y) * Math.cos(angle);
    const isoY = (x + y) * Math.sin(angle) - z;
    return { x: centerX + isoX * scale, y: centerY + isoY * scale };
  } else {
    // 正俯视: X向右, Y向上
    return { x: centerX + x * scale, y: centerY - y * scale };
  }
};
```

### 10.5 关键实现细节

**1. 移除侧视图 (side) 和正视图 (front):**
- 这些视图需要完全不同的2D投影逻辑
- 容易造成3D/2D混合的混乱
- 专注ISO和Top两个视图足以完成装配定位

**2. 统一的颜色系统:**

```typescript
  grid: isDark ? '#30363d' : '#e5e7eb',
```

**3. 组件Z轴排序:**
```typescript
// Z-buffer排序: 低处的组件先画，高处的后画(覆盖)
[...components]
  .sort((a, b) => (a.mountZ || 0) - (b.mountZ || 0))
  .map(c => renderComponent(c))
```

### 10.6 设计约束固化

**新增规范条目:**

```
□ VIS-01: 所有3D元素必须使用统一的 projectPoint 函数
□ VIS-02: 禁止在ISO视图中使用未投影的2D形状
□ VIS-03: TOP视图必须显示为纯俯视角(X-Y平面投影)
□ VIS-04: 组件和底盘使用相同的缩放比例(scale)
□ VIS-05: 只允许ISO和Top两种视图模式
□ VIS-06: 组件按Z坐标排序渲染
```
