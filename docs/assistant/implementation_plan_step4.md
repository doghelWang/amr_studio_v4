# 安装坐标图形化可视化重构方案 (Step 4)

## 1. 目标描述
将现有的纯文字输入式安装位姿配置（Step 4）升级为 **2.5D 轴侧图 + 2D 多视角** 的图形化交互界面。确保用户能直观观察到各个传感器、驱动器在机器人本体上的物理分布。

## 2. 交互设计 (UI/UX)
- **多视角联动**:
  - **主视图 (2.5D Isometric)**: 采用 60°/45° 轴侧投影，展示机器人的立体空间布局。
  - **辅助视图 (Top/Side)**: 提供俯视图 (X-Y) 与侧视图 (X-Z) 的 2D 投影。
- **动态同步**:
  - Step 3 中新增的组件会自动出现在 Step 4 的画布中。
  - 用户在右侧面板修改数值，左侧图形实时平移/旋转。
- **高亮关联**:
  - 鼠标悬停在列表项时，对应的 3D 坐标点高亮闪烁。

## 3. 拟定变更

### Frontend [NEW]
- **`src/components/visualizer/CoordinateVisualizer.tsx`**: 核心绘图组件。
  - 使用 SVG 构建轻量级 2.5D 渲染器。
  - 包含坐标轴 (X-Red, Y-Green, Z-Blue) 辅助线。
  - 支持多视角切换或并列展示。

### Frontend [MODIFY]
- **`src/components/wizard/MountingStep.tsx`**: 布局重构。
  - **左侧 (70%)**: 放置 `CoordinateVisualizer`。
  - **右侧 (30%)**: 放置响应式的坐标编辑列表（精简版卡片）。

## 4. 验证计划
### 自动化验证
- 验证 Zustand Store 中的 `components` 数组变化时，Visualizer 是否触发重绘。
- 验证极致坐标（如 X=2000, Z=1000）是否会导致图形溢出画布（需实现自适应缩放/Auto-Zoom）。

### 手动验证
- 在"感知避障"中添加三个 Lidar，切换到第 4 步，确认它们呈等腰三角形或其他物理位置分布。
