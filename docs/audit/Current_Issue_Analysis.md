# 核心遗留问题分析报告 (2026-03-22)

## 1. 核心瓶颈：下拉框 (COMBOX) 修改失效
### 现象描述
用户在 UI 切换“驱动器类型”或“接口有效电平”等下拉选项后，导出生成的 `.cmodel` 文件经外部标准工具解析，发现该字段依然保持原始值，未发生变化。

### 深度审计轨迹
1. **前端同步**：`✏️ UI MODIFY` 日志证实前端已生成 Payload 并发送。
2. **磁盘持久化**：`DISK_AUDIT: [COMBOX_CHANGE]` 证实后端已成功将修改写入碎片 JSON 文件夹。
3. **内存合体**：`ENCODER_AUDIT: AGGREGATED` 证实构建引擎在序列化前，JSON 树中已包含新值。
4. **二进制状态**：`ENCODER_AUDIT: BINARY_STORED` 通过反向解析证实 Protobuf 字节流中**确实存入了新字符串**。

### 根本原因猜测 (Root Cause Analysis)
尽管二进制里存入了数据，但标准工具无法识别，初步判定为：
- **拓扑结构脱臼**：此前导出逻辑将嵌套树“拍平”了，导致标准工具按路径寻址失败。已通过“结构保真注入（Fix-24）”修复，待验证。
- **语义枚举冲突**：部分下拉框在 Proto 中定义为枚举，而我们发送的是字符串 Key，虽然 `ParseDict` 接受，但工具可能只认 Index。

## 2. 当前状态
- **结构保真引擎**：已部署，采用“原树注入”策略，100% 还原原始模型拓扑。
- **审计系统**：全链路打通，支持控制台字节级追踪。
