## 2. 核心问题深度复盘 (Critical Issues)

### 2.1 拓扑链路识别断路
*   **底层成因**: 工业模型（如 AOBO）并非依靠 `parentNodeUuid` 构建动力树，而是通过 **“私有属性语义关联”** 与 **“接口电气接线”** 交叉定义。
*   **识别逻辑偏差**: 之前的逻辑试图通过中文别名（Alias）进行匹配，导致在拥有 8 个同名电机（步科电机）的 AOBO 模型中发生了严重的“覆盖”与“错位”。
*   **深度嵌套障碍**: 关联编码器等核心字段被深埋在 `angleSensor` -> `DATA_COMBOX` -> `arrayCmobEle` 的嵌套层级中，现有的扁平扫描器无法触达。

### 2.2 数据映射密度不足
*   **字段丢失**: 忽略了 `DATA_FIXED_E` 类型中的 **`stringFix`** 字段（该字段在工业协议中用于存储关联组件的 ID）。
*   **类型识别偏差**: 漏掉了 `int32Value` 等 Protobuf 变体，导致电机转速、编码器位数等关键参数在 UI 中显示为空。
*   **接口路径错误**: `interfaceParams` 解析路径错误，导致导入后“电气接口”面板无法正确展示物理连线。

### 2.3 UI 架构稳定性问题
*   **变量引用错误**: 多次出现 `renderHeaderField` 或 `pair` 未定义的 ReferenceError，反映出在复杂组件重构时缺乏足够的回归测试。
*   **交互逻辑断裂**: 2-3 界面在多次重构中丢失了“左视图、右列表、下属性”的平衡，未能实现“点击树节点即配置属性”的工业规范。
