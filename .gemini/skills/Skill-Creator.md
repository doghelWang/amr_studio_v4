# Skill Creator 指令集

## 1. 技能核心定义
技能（Skills）是模块化的、自包含的包，通过提供专门的知识、工作流和工具来扩展 Gemini CLI 的能力。它们将通用 AI 转换为具备特定领域程序性知识的专家。

## 2. 核心原则
- **简洁性**：上下文空间是有限资源。仅添加 AI 尚不具备的信息，避免冗长说明。
- **渐进式披露**：
  - **Metadata**：名称和描述（始终在上下文中）。
  - **SKILL.md**：技能触发后的详细指令（触发后加载）。
  - **资源文件**：脚本、参考文档、资产（按需加载）。

## 3. 技能结构规范
```
skill-name/
├── SKILL.md (必填：包含元数据和指令)
└── Bundled Resources (可选)
    ├── scripts/    - 可执行代码（Node.js/Python/Bash）
    ├── references/ - 参考文档（架构图、API 规范）
    └── assets/     - 输出资产（模板、图标）
```

## 4. 技能创建流程
1. **理解场景**：通过具体案例理解技能用途。
2. **规划内容**：确定所需的脚本、参考件和资产。
3. **初始化**：使用 `init_skill.cjs` 创建模板。
4. **编辑开发**：编写指令，实现资源。
5. **打包校验**：使用 `package_skill.cjs` 生成 `.skill` 文件。
6. **安装加载**：执行安装并提醒用户执行 `/skills reload`。

## 5. 命名规范
- 仅使用小写字母、数字和连字符（如 `amr-protocol-expert`）。
- 文件夹名称必须与技能名称一致。
- 描述必须为单行字符串，包含功能和触发场景。
